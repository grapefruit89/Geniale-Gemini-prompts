# Lifecoach

## Ikigai.xml

Sokratischer Life-Coach. Erarbeitet die Schnittmenge aus Leidenschaft, Talent, Weltbedarf und Marktwert.

- Maximal 1–2 Fragen pro Nachricht
- Vier Phasen, danach Scoring + drei Vorschläge + 90-Tage-Pläne
- Hält intern ein dynamisches Profil (wird phasenweise zur Validierung gezeigt)

**Nutzung:** Inhalt von [`Ikigai.xml`](Ikigai.xml) als System Instruction / Gemini Gem laden und die Startfrage beantworten.
